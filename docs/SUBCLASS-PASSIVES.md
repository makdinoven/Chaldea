# Подклассы и пассивки — дизайн-бэклог

> Живой документ. Здесь собраны все 21 подкласс (7 × 3 класса), их концепт, идея
> фирменной пассивки и **тир сложности** относительно текущего боевого движка.
> Сами пассивки реализуем **после** доработки боевой системы (таргетинг, групповые
> бои, контроль). Первый шаг — связка узла дерева с подклассом (без пассивок).

## Легенда тиров

| Тир | Что значит | Готовность движка |
|-----|-----------|-------------------|
| 🟢 **T1** | Статовая / скилловая пассивка: «+X к атрибуту», «+X%». | Готово. Работает через перк-движок (`character-attributes-service`, `Perk`/`CharacterPerk`, `perk_evaluator.py`) + навыки в дереве подкласса. |
| 🟡 **T2** | Контекстный эффект: «+урон по мобам», «+опыт с убийства». | Нужен один точечный хук (в расчёте урона есть `is_npc`; в начислении награды есть `xp_reward`). |
| 🔴 **T3** | Новая боевая механика: отражение, скейл от HP, условные бафы. | Нужна новая логика в `battle-service` + **пререквизит**: загрузка пассивок персонажа в бой на старте (сейчас её нет). |
| 🧱 **PILLAR** | Упирается в отсутствующую опору движка (см. ниже). | Блокер. Реализуем опору, потом подкласс. |

## Опоры боевого движка (статус)

Проверено по коду `battle-service` (`battle_engine.py`, `buffs.py`, `main.py`, `redis_state.py`):

1. ⬜ **Загрузка пассивок персонажа в бой на старте.** Сейчас все эффекты приходят
   только от каста навыков в бою; точки «вшить постоянный эффект персонажа» нет.
   → Пререквизит для ВСЕХ T3-пассивок (Хранитель, Берсерк, Гладиатор, Сейбер).
   **Самая фундаментальная оставшаяся опора.**
2. ⬜ **Таргетинг по союзнику.** `target_side` понимает только `self` / `enemy`.
   Бафнуть/полечить тиммейта нельзя. → Открывает весь саппорт-архетип:
   **Бард, Ауромант, Эфириад.**
3. ✅ **Энфорс контроля.** DONE (FEAT-143): Stun/Poison-паралич пропускают ход,
   Knockdown/Windburn блокируют тип навыка. → **Монах, Фокусник** разблокированы.
4. 🟡 **Мультицель / рикошет / AoE.** Одиночный **выбор цели уже есть** (`target_id`,
   групповые бои). Осталось: мультицель/рикошет/AoE. → **Механик** (шрапнель).
5. ✅ **Ловкость → инициатива.** DONE (FEAT-143): инициатива = ловкость×1.0 +
   (сила+инт)×0.75, инициатор первый. → «проворные» (Агент, Ассасин, Арчер).

Также DONE: сложные эффекты — периодический урон (кровотечение/ожог/яд),
стат/резист/урон-модификаторы (ArmorBreak/Freeze/Electrify/Daze/Wet/Holy/Curse).

## План реализации (порядок)

1. **Связка узла ↔ подкласс (СЕЙЧАС).** Хардкод-реестр подклассов в `skills-service`,
   `subclass_key` на узле `subclass_choice`, дропдаун в админке, детерминированная
   навигация игрока, описание-превью из реестра. **Без пассивок.**
2. Фиксация выбора подкласса за персонажем (`character_subclass`).
3. Опоры боёвки по охвату: загрузка пассивок в бой → таргет союзника → контроль →
   мультицель.
4. Пассивки подклассов поверх перк-движка (T1/T2), затем T3 по мере готовности опор.
