## 1. Feature Brief (RU)

На длинных историях список сообщений не должен грузить браузер тяжёлым DOM. Реализовано через
CSS `content-visibility: auto` — браузер пропускает рендер/лейаут/пейнт off-screen сообщений,
сохраняя при этом место под них (`contain-intrinsic-size`).

### Почему не react-window
Список содержит элементы переменной высоты (картинки, реакции, разделители, цитаты) и тонкую
логику скролла/якоря (сохранение позиции при подгрузке старых, пилюля «новые», доскролл к низу),
которую мы специально чинили. Полноценное JS-окно (react-window) — крупный рискованный рефактор
с шансом регрессии в скролле. `content-visibility` даёт основной выигрыш по производительности
без изменения логики, новых зависимостей и graceful-деградацией в браузерах без поддержки.

## 2-5. Technical (frontend-only)

- `components/Messenger/MessageArea.tsx` — каждое сообщение в списке обёрнуто в `div` со
  `style={{ contentVisibility: 'auto', containIntrinsicSize: 'auto 64px' }}`. Скролл-контейнер
  имеет `overflow-anchor: auto` (по умолчанию), что нивелирует сдвиги при дорендере off-screen
  элементов.
