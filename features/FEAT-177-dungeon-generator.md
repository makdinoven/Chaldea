## 1. Feature Brief (filled by PM — in Russian)

### Описание
Админ задаёт параметры (оформление, этажи, комнат на этаж, уровень, размер группы, сложность, что включать)
и получает готовый черновик подземелья: комнаты, коридоры, мобы, добыча, ключи и замки, ловушки, тайники,
тексты-заготовки. Черновик — обычные комнаты и коридоры, их правят в существующем редакторе.

### Бизнес-правила
- Только для админов (права `dungeons:edit`), игрокам генератор недоступен.
- Генерация по одному подземелью за раз; если в нём уже есть комнаты — только с явным подтверждением замены.
- Нельзя генерировать, пока в подземелье находится группа.
- После генерации подземелье выключается (черновик) — админ включает его сам после правок.
- Путь от входа до босса гарантирован; каждый ключ лежит там, куда можно дойти до его двери.
- Тексты — заготовки под оформление; лор админ пишет сам.
- Мобы и добыча подбираются по уровню автоматически; админ может задать свои списки.
- Один и тот же seed даёт ту же карту (можно перегенерировать с другим).

### UX
1. Админ создаёт подземелье обычной формой (название, локация…).
2. В редакторе жмёт «Сгенерировать», задаёт параметры.
3. Получает карту в редакторе, правит, проверяет, включает.

### Вопросы к пользователю
- [x] Для кого? → только админы
- [x] Новая карта на каждый забег? → пока нет, только черновики
- [x] Тексты? → заготовки
